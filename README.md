# Webové projekty

Centrální repozitář pro projekty vytvořené pomocí různých no-code / AI nástrojů.

## Struktura

- `Lovable/` — projekty z Lovable
- `Webflow/` — projekty z Webflow
- `Macaly/` — projekty z Macaly
- `Relume/` — projekty z Relume

Každý projekt může mít vlastní podsložku s názvem projektu.
